# КОНЕЧНАЯ — веб-демо

Играбельный прототип по дизайн-документу: линия **Дали**, пустыня у Станции 07.
Работает в браузере, управление под телефон. Внешних ассетов нет — вся графика,
шрифт и звук генерируются кодом.

## Как запустить

- **GitHub Pages:** Settings → Pages → Source: *Deploy from a branch* →
  ветка `claude/awaiting-instructions-r9rdfx`, папка `/ (root)` → Save.
  Через минуту игра будет по адресу `https://<ник>.github.io/und/`.
- **Локально:** любой статический сервер, например `python3 -m http.server`,
  затем открыть `http://localhost:8000`. (Можно и просто открыть `index.html`
  файлом — внешних загрузок нет.)

## Управление

| | Телефон | Клавиатура |
|---|---|---|
| Ходить / уворачиваться | стик слева (появляется под пальцем) | стрелки или WASD |
| Действие, подтвердить | кнопка **Z** или тап по правой половине | Z / Enter / пробел |
| Отмена | кнопка **X** | X / Shift / Esc |
| Меню боя | тап прямо по кнопке | стрелки + Z |

Сверху справа — звук и полный экран.

## Что есть в демо

**Мир.** Станция 07 по мотивам референса: брошенный вагон, вывеска, будка со
вычеркнутым расписанием, оборванные рельсы, колодец, руины, тропа на юг ко
второй станции. Восемь точек с текстом, три бродячих монстра, рычаг вызова
поезда — он же финал демо.

**Бой.** Механика из документа, которая учит идеологии Дали:

- **Окно первого удара.** В начале боя есть короткое окно: успел — бесплатный
  сильный удар, не успел — монстр бьёт первым и сильнее.
- **Окно сжимается** от боя к бою: 1.30 с → 0.95 с → 0.62 с.
- **Блок отбирают.** В первом бою он есть («я не буду бить» — боя не будет).
  Дальше он остаётся в интерфейсе, но перечёркнут — утрата видна.
- **Бегство.** У монстра с малым здоровьем появляется реплика, что он хочет
  убежать, и блок превращается в «ОТПУСТИТЬ». Но если убито двое — кнопка не
  появляется вовсе: отпускать уже нечем.
- **Милосердие стоит дорого.** Убил — поел (+ОЗ, +сытость). Отпустил — остался
  голодным. Сытость капает всё время, на нуле начинает съедать здоровье.
- **Уворот** от снарядов в коробке-арене, у каждого монстра свой узор.
- **ОСМОТР** («проверить» / «заговорить») тратит ход и объясняет то, чего Дали
  не знает: они нападают, потому что тоже голодны.

**Концовка** зависит от того, как игрок себя вёл: прошёл мимо, отпускал, убивал
или смешивал. Финальный экран показывает счётчики.

## Чего в демо нет

Линии Рича, монстра-спасителя, Идеолога, зимнего пролога и встречи братьев —
в документе они ещё не проработаны.

## Структура

```
index.html
css/style.css        экран, сенсорное управление
js/font.js           растровый шрифт 5x7, кириллица (нарисован вручную)
js/palette.js        палитра
js/textures.js       вся графика: тайлы, спрайты, постройки, монстры
js/audio.js          синтезатор пищалок и фоновой петли на WebAudio
js/input.js          клавиатура + стик/кнопки/тапы
js/ui.js             рамки, текстовое окно с печатающимся текстом
js/world.js          карта, объекты, глубина, свет
js/battle.js         бой целиком
js/game.js           состояния, голод, диалоги, концовки
```
